# YOU TV - Live TV & IPTV Web Player

A sleek, modern, cinema-grade **Live TV & IPTV Web Application** designed for PC, Mac, Android, Smart TVs, and mobile browsers.

---

## Features

- **103 Curated Live TV & Regional Channels**:
  - **News**: Puthiya Thalaimurai, Polimer News, Thanthi TV, News7 Tamil, Sun News, News18 Tamil Nadu, Kalaignar Seithigal, Sathiyam TV, DD Podhigai, News J, Malaimurasu, IBC Tamil News.
  - **Entertainment**: Sun TV, Star Vijay, Zee Tamil, Kalaignar TV, Jaya TV, Raj TV, Captain TV, Mega TV, Vasanth TV, Vendhar TV, Shakthi TV, Dan TV, Deepam TV, Nethra TV, Vasantham TV.
  - **Movies**: KTV, Vijay Super, Zee Thirai, Murasu TV, Raj Digital Plus, J Movie.
  - **Music**: Sun Music, Isaiaruvi, Raj Musix, Jaya Max, 7S Music.
  - **Comedy**: Adithya TV, Sirippoli.
  - **Devotional**: Sri Sankara TV, SVBC Tamil (Tirupati Balaji Live), Sai TV, Madha TV (Velankanni), Angel TV, Nambikkai TV.
  - **Kids & Info**: Chutti TV, Chithiram TV, Discovery Channel Tamil, History TV18 Tamil.
  - **Tamil Local & Cable**: Puthuyugam TV, Makkal TV, Lotus News, Cauvery News, Tamilan TV, Moon TV, Win TV, Pepper TV, Velicham TV, Malar TV, MK TV, MK Six, Arra TV, Vendhar TV, Captain TV, Captain News, Mega TV, Mega 24, Thalam TV, Imayam TV, Vaanavil TV, Vasanth TV, Star Tamil TV, and 30+ regional cable streams.
  - **Sri Lanka & Global**: Shakthi TV, Dan Tamil Oli, Nethra TV, Vasantham TV, Deepam TV Europe.

- **Dual-Engine Player (1080p Live Stream + HLS.js)**:
  - Responsive high-definition streaming with intelligent HLS.js stream playback and fallback.
  - Automatic unmuted audio playback on user interaction.
  - Picture-in-Picture (PiP) and Fullscreen theater mode.
  - Channel Grid and List views with category filtering and instant search.

- **Security & Access Control (RBAC)**:
  - Separate login views for Regular Viewers and Administrators.
  - Device limits per user with remote device logout capability.
  - Channel access management (full access or specific selected channels).
  - Watch timer expiration and account expiry limits.
  - Admin password management and channel customization.

---

## Getting Started

Open `index.html` in any modern web browser or deploy directly with GitHub Pages.
